# function: rest_api_body

Render an API Gateway REST API body from an OpenAPI document. Returns compact JSON for `aws_api_gateway_rest_api.body`, keeping the
document's key order, so the same inputs always give the same body.

## Example Usage

```terraform
resource "aws_api_gateway_rest_api" "this" {
  name              = "orders"
  put_rest_api_mode = "overwrite"

  body = provider::apigw-openapi::rest_api_body(file("${path.module}/openapi.yaml"), {
    integration = {
      base_uri                = "http://orders.internal.example.com"
      connection_id           = aws_apigatewayv2_vpc_link.this.id
      integration_target      = data.aws_lb.internal.arn
      preserve_forwarded_host = true
    }
    authorizer = {
      security_scheme                = "LambdaToken"
      uri                            = aws_lambda_function.authorizer.invoke_arn
      credentials                    = aws_iam_role.authorizer.arn
      result_ttl_in_seconds          = 300
      identity_validation_expression = "^Bearer [-0-9a-zA-Z\\._]*$"
      request_headers = [
        { name = "x-user-id", value = "context.authorizer.userId" },
      ]
    }
    excluded_paths      = ["/internal/health"]
    catch_all_not_found = true
  })

  endpoint_configuration {
    types = ["REGIONAL"]
  }
}
```

If an argument is unknown at plan time (e.g. a VPC link being created), so is the body,
and anything keyed on it, such as a deployment trigger. To keep the body known, pass a
fixed placeholder and `replace()` it in the result.

## Behaviour

1. Parses the document: YAML 1.2 core schema, one document; JSON is valid YAML.
2. Replaces each local `$ref` (`#/...`) with its target. Remote refs are not supported.
3. Removes `excluded_paths`.
4. With `authorizer`, adds a security scheme and applies it to every operation without
   its own `security`.
5. Adds an `HTTP_PROXY` integration to each `get`, `post`, `put`, `patch`, `delete` and
   `head` operation without an `x-amazon-apigateway-integration`. It maps path
   parameters, `X-Forwarded-Host` if enabled, and `authorizer.request_headers` where the
   authorizer runs: no `security` of its own, or a requirement naming its scheme.
6. Applies `path_rewrites`, then adds the catch-all 404 if enabled.

## Arguments

<!-- arguments generated by tfplugindocs -->
1. `spec` (String) OpenAPI document, YAML or JSON, e.g. `file("openapi.yaml")`.
1. `options` (Dynamic, Nullable) Object; see [`options`](#options).

### `options`

All attributes are optional; unknown attributes are an error.

| Attribute | Type | Description |
|---|---|---|
| `integration` | object | Default backend. Without it, no integrations are added. |
| `secondary_integration` | object | Second backend. Paths it matches take precedence over `integration`. |
| `authorizer` | object | Lambda token authorizer. |
| `strip_prefix` | string | Removed from public paths (first occurrence); integration URIs keep the full path. |
| `excluded_paths` | list(string) | Paths removed from the API. Each must exist in the document. |
| `path_rewrites` | map(string) | Public path to backend path; replaces the path in the integration URIs on that path. |
| `catch_all_not_found` | bool | Add a `/{proxy+}` `MOCK` returning 404 for methods the document doesn't define there. Default `false`. |

`integration` and `secondary_integration`:

| Attribute | Type | Description |
|---|---|---|
| `base_uri` | string | Required. URI prefix; the operation's path is appended, e.g. `http://host/prefix`. |
| `connection_id` | string | VPC link ID. Sets `connectionType = VPC_LINK`. |
| `integration_target` | string | Load balancer ARN, for VPC links v2. |
| `paths` | list(string) | Path prefixes routed here; `/a` matches `/a` and `/a/b`, not `/ab`. Default: all paths for `integration`, none for `secondary_integration`. |
| `ignored_paths` | list(string) | Path prefixes excluded, matched the same way. |
| `preserve_forwarded_host` | bool | Map `X-Forwarded-Host` from `context.domainName`. Default `false`. |

`authorizer`:

| Attribute | Type | Description |
|---|---|---|
| `security_scheme` | string | Required. Name of the scheme added to `components.securitySchemes`. |
| `uri` | string | Required. The authorizer's invoke URI. |
| `credentials` | string | IAM role API Gateway assumes to invoke it. |
| `result_ttl_in_seconds` | number | Default `300`. |
| `header` | string | Header carrying the token. Default `Authorization`. |
| `identity_validation_expression` | string | Regular expression the token must match. |
| `request_headers` | list(object({name, value})) | Backend request headers and their values, e.g. `context.authorizer.userId`, in order. |
